# Pricing Benchmark: Buyer Arena's Market

Research date: 2026-09-25 to 2026-09-26. Purpose: set price anchors for Buyer Arena's planned commercial layer: hosted runs, team dashboards, PR/CI integration, calibration, enterprise, and services.

## 0. How to read this document (verification levels)

In this research container, direct HTTP fetches of vendor websites were **blocked by the egress proxy**: WebFetch and curl both failed for every `*.com`/`*.dev` pricing page tried. Only `raw.githubusercontent.com` was reachable. Each figure therefore carries one of these tags:

| Tag   | Meaning                                                                                                                                                                                                                     | Use as price anchor?                                       |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **V** | **Verified**: read by me directly from the vendor's own published source. This is the Markdown/TSX source of the official pricing page or pricing docs in the vendor's public GitHub repo, main branch, read 2026-09-25/26. | Yes                                                        |
| **S** | Official-domain page (URL cited) as summarised by the WebSearch index. The live page was **not fetched**. Numbers are from the vendor's own domain but are unconfirmed and could be stale.                                  | Provisional. Re-check in a browser before quoting publicly |
| **U** | **UNVERIFIED — not reached.** The official page was not reachable and the search index did not surface its numbers. Any figure shown comes from a third party, is marked "3rd-party lead", and is **not** an anchor.        | No                                                         |

All prices are USD unless stated otherwise. "/mo" means per month as published. "annual" means the published price assumes annual billing.

## 7. Implications for Buyer Arena

### 7.1 Common pricing units in this market

| Unit                                              | Who uses it                                                                                        | Fit for Buyer Arena                                                                                                    |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Usage events** (traces, spans, units, requests) | Langfuse, Braintrust, Arize, Helicone, PostHog, Sentry                                             | Maps weakly. BA produces far fewer, heavier artifacts.                                                                 |
| **Runs / check runs / credits per step**          | Checkly (per 1k browser runs), Momentic ($0.01875/step), Octomind (cloud runs), Promptfoo (probes) | **Best fit** for hosted synthetic-buyer journeys. Meter "buyer-journey runs" or "browser minutes".                     |
| **Seats**                                         | LangSmith $39, Confident AI, W&B                                                                   | Common in eval tools, but penalises team adoption. Langfuse, Arize, Helicone and Momentic advertise "unlimited users". |
| **Contributors / committers**                     | Semgrep ($15–30), Snyk ($25), GitGuardian, Socket ($8), Sentry Seer ($40)                          | Good fit for the **PR/CI and agent-eval** product: price per active contributor or repo.                               |
